# ClassMaster LK 🧑‍🏫📘

**ClassMaster LK** is a secure, offline desktop application designed to help Sri Lankan tutors and small-scale tuition providers manage their classes, students, attendance, and payments — all in one simple dashboard. Built with  user-friendly solution that replaces messy paperwork and streamlines daily administrative tasks.

---

## 🔧 Core Features

### ✅ Dashboard
- Overview of today’s scheduled classes
- Summary of pending student fee payments


### 🏫 Class Management
- Create and view tuition classes
- Organize by subject, time, and grade
- View all assigned students per class

### 👩‍🎓 Student Management
- Add new students with contact details
- Assign students to one or more classes
- View complete student profiles and payment history

### 📝 Fee Tracking
- Track monthly fee payments (Paid, Unpaid)
- Filter data by class, date, or payment status

### 📄 Reports (PDF Export)
- Generate fee reports showing unpaid students
- Shareable with parents for transparency

---

## 💻 Technology Stack

- **Frontend**: React.js  
- **Backend**: Python + Flask  
- **Desktop Build**: Electron.js / PyInstaller  
- **Database**: SQLite (local storage)
